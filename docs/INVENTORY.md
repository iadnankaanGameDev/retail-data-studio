# Source publication inventory

RetailDataAutomation is the single source workspace. No new project copy is required.

| Included in GitHub preparation | Kept locally and excluded |
| --- | --- |
| src/ and application assets | data/ (all existing private data, databases and backups) |
| tests/ including the synthetic example test | .venv/ (the active Python 3.12 environment) |
| scripts/ launch, build, packaging and QA helpers | artifacts/ (license provenance, source archives, acceptance evidence and local tools) |
| installer/ source and version metadata | build/, dist/, executable distributions and caches |
| examples/ synthetic catalogs and sales | cleanup inventories and logs containing local paths |
| docs/ usage, architecture, license review and notices | customer Setup, stored separately in the existing delivery directory |
| README, requirements, spec and batch launch/build files | credentials, private CSVs and local configuration |

The exact publication file list is generated by the cleanup audit. Only the three
synthetic example CSVs and explicit license-inventory CSVs are allowed. Do not add
ignored files with git add -f. No GitHub push has been performed.
